# EduHITZone | Online Study Platform With AI

Industry project from HIT university.
This is an online study platform made with [Go](https://go.dev/) and [htmx](https://htmx.org/)

## Feature
1. Video + Text uploads for courses.
2. SQLite database.
3. Ajax with hx attributes.
4. OpenAI ChatGPT integration for summarising lectures and writing quizzes.
